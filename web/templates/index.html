These settings never change any files. They only decide what the Reorganize dialog suggests. Nothing is renamed, moved or deleted until you select it in the dialog and click Do it (dry run is on by default).

The Naming Format defines what a compliant folder and file name looks like. Reorganize compares the items shown by your current filters against it and suggests changes.

Placeholders: {title} (required) and {year}. Values come from the NFO when present, otherwise from the folder/file name (scene names such as Inception.2010.1080p are understood as Inception, 2010). An item without a known year gets no suggestion when the format uses {year}.
Rules: the result must be a single name — none of \ / : * ? " < > |, not ending with a dot or space. Sanitize rule (used for titles and for existing names, see below): : becomes - , other illegal characters are dropped and trailing dots/spaces are removed (Alien: Covenant → Alien - Covenant).

Name of a series folder. Must contain {title}; {year} is allowed. Episode files and season folders are never renamed to a format — but if their names contain illegal characters or end with a dot/space, Reorganize offers to sanitize them (see Sanitize names below). Preview:
Off → never suggested. On → suggested in the Reorganize dialog, applied only if you select it.
An NFO named movie.nfo or after the video already works for Jellyfin and is never renamed. A single NFO with any other name is ignored by Jellyfin — it is suggested for renaming to the video's name. When a movie has several NFOs, the dialog lets you choose: use the best (the others are deleted; the best keeps its name if it is movie.nfo or named after the video, otherwise it gets the video's name), delete all (Jellyfin recreates it on its next scan), or leave as is (the default). NFOs with the video's name always follow a renamed video.
